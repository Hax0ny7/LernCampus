Materiallager · Ziehen oder antippen

Ziehe die Gegenstände in den passenden Bereich. Die Auswahl ist ein vereinfachtes Lernmodell.

Wichtig: Sterilität ist nicht allein eine Materialeigenschaft. Ob und wie ein Gegenstand auf das sterile Feld kommt, hängt von Verpackung, Arbeitsschritt, lokaler SOP und verwendetem Set ab. Die dargestellte Zuordnung ist eine didaktische Vereinfachung und muss vor einem klinischen Einsatz fachlich geprüft werden.

Themen freischalten

Änderungen werden ausschließlich in diesem Browser gespeichert. Für eine gemeinsame Freischaltung auf allen Geräten ist später eine zentrale Veröffentlichung oder ein Server nötig. Dies ist kein passwortgeschützter Adminbereich.
